# UIAPduino Block Workshop

UIAPduinoを使い、小学生がブラウザだけで電子工作とブロックプログラミングを体験できる教材を目指すプロジェクトです。

最初のバージョンでは、Blocklyで組み立てたプログラムをブラウザ上で実行し、WebHID経由でUIAPduinoを操作します。サイトはGitHub Pagesで公開し、ChromeまたはEdgeから利用する想定です。
