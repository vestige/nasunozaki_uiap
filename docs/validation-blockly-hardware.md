ボード単独実行は #46。以下は確認手順であり、実機合格の記録ではない。

## 準備

1. USBを抜いた状態で配線する。タクトスイッチはD5–GND、NeoPixelはD8–DIN・5V・GND。
2. ボタンを押さず通常接続し、ブラウザで「ボードに接続」を選ぶ。
3. `examples/blockly/tact-neopixel-toggle.uiap.json` を「作品ファイルを開く」で読み込む。現在の作品は先にファイル保存する。
4. 「画面でためす」で確認後、同じ作品を「ボードでためす」で確認する。

## 続けて確認すること

`examples/blockly/logic-check.uiap.json` は1～6番で順に＝・≠・＜・≤・＞・≥の成立／不成立を確認する。7番は「かつ／または」の全真理値表と真偽値比較、8番は数値変数と入れ子分岐を確認する。各LEDは合格なら緑、不一致なら赤（明るさ20%）。最後は待機し、停止するまで表示を保持する。

- 2026-10-06: 保存・再読込を含む自動テストで8灯とも緑を確認。
- 2026-10-06: ブラウザの画面実行で8灯とも緑（表示色 #003300）を確認。
- 2026-10-06: 利用者が実機の8灯すべて緑で、赤・消灯がないことを目視確認。画面実行と一致。

- 数値の比較6種類、真偽値の一致・不一致、かつ／または、入れ子の分岐。
- 未初期化変数・型の不一致・通信timeoutが実行を終了すること。
- 保存して再読込した作品が同じ動きをすること。
