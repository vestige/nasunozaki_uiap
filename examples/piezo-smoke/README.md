# 圧電部品の短時間試験（#49）

型番未確定の部品の発音を確認するための、一時的な試験スケッチ。
正式なランタイム機能ではない。通常のBlockly/WebHID命令には応答しない。

## 配線

USBを外して `D6 / PC4 → 1kΩ → 圧電部品 → GND`。
今回の圧電部品はユーザー確認で極性なし。2本の足のどちらを抵抗側につないでもよい。電源PINにはつながない。
使用する部品は発振回路なしの圧電スピーカーを想定している。
型番未確定部品の安全性を保証するものではない。

## 動作

起動から約1.5秒後に4kHzを0.2秒、その後440Hzを0.5秒、523Hzを0.5秒。
音の間は無音。発音中だけ内蔵LEDが点灯し、約4秒後に音とLEDが停止する。
音を繰り返すにはUSBを挿し直す。長い連続発音はしない。
4kHzは候補PKM13EPYH系の共振付近、440/523Hzは音の高さが変わるかを見るため。
低い音が小さくても、部品の故障やプログラム失敗と即断しない。
NeoPixelは起動時に全消灯する。タクトスイッチは操作しない。

波形生成はcore 1.2.14のPWMmin、TIM1 CH4だけを使う。
停止期限はloopのmillis差分で管理し、停止時にD6をLOWへ戻す。
ソフトウェアの音生成ループや時間指定tone()の待機は使わない。

## ビルド・書き込みの注意

通常のランタイムとは別の出力ディレクトリ `.build/piezo-smoke` にビルドする。
既存の14KiB制限の`uiap_standalone.ld`を使い、作品領域をリンク対象にしない。
配布用のbin/zipやbuild-infoは更新しない。

書き込みはユーザーの確認と書き込みモードへの接続後に行う。
一時的に現在のランタイムを置き換えるので、試験終了後は通常のランタイムへ戻す。
導入済みuiapflashはbin範囲の64バイト単位の差分書き込みとされるが、
作品領域の保持は実機で未確認。大切な作品は先にファイル保存し、必要なら
Flashバックアップも取る。読み戻し未実施で「作品は確実に残る」と保証しない。

設計の正本: [圧電スピーカー設計メモ](../../docs/spec-piezo.md)。
